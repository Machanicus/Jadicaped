# RuneLite Community Launch Plan

## Goal

Position the plugin as a retrospective learning tool for Jad attempt review, not as a live assistive aid.

## What to emphasize

- Static reminder overlay only
- No automation
- No prediction
- No live NPC animation tracking
- Passive post-death summary only
- Intended for calmer, reflective play and self-review

## Forum framing

Recommended title candidates:

- Jad Focus Mode + Post-Death Summary
- Retrospective Jad Review Overlay
- Calm Jad Practice Panel
- Static Jad Reminder and Attempt Review

Suggested intro:

> This plugin is designed as a static reminder and review tool for Jad attempts. It does not provide live combat guidance or automate actions. The panel updates after death or attempt end so players can review prayer use, movement, resources, and mistakes without affecting the live fight.

## YouTube framing

Good viewers to target:

- Jad learners
- Puzzle and phase-practice players
- Players looking for calm, low-noise overlays
- RuneLite users who prefer reflective analysis over live assistance

Recommended video topics:

1. "A calm Jad setup that stays static and uses a post-death summary"
2. "What the post-death summary tells me after a Jad death"
3. "Reviewing prayer mistakes without using live combat assistance"
4. "Building a non-reactive Jad overlay for practice"

## Content rules

- do not use language that suggests live assistance or automated prayers
- keep screenshots focused on the post-death panel and static reminders
- clearly describe that the summary appears after death
- show the plugin as a learning tool, not a decision engine
- avoid implying the plugin is giving live tactical advice while the fight is active

## Improvement roadmap

- add a compact mode for a less cluttered panel
- add the ability to compare recent attempts
- add CSV export for analysis outside the client
- add clearer visual grouping for mistake categories
- add a toggle to hide optional fields when the panel feels too dense
- add a minimal “attempt trend” view to show improvement over time

## Trust checklist before publishing

- build and run successfully
- only late-stage summary updates after death
- no live prediction, no animations, no auto-prayer behavior
- documentation states the retrospective-only scope clearly
- community-facing wording stays neutral, precise, and honest
- screenshots and demos match the actual static, non-reactive behavior
